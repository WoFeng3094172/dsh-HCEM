# 前世记忆（reincarnation）

把**旧 AI 整理好的记忆文件**放进这个文件夹，HCEM 启动时会自动融合，不需要手动改数据库。

## 要放哪些文件

详细做法见项目根目录的 `前世记忆打包指南.txt`，简单说：

| 文件 | 内容 |
|---|---|
| `persona.md` | 旧 AI 的角色卡——它是谁、性格、说话方式 |
| `journal.md` | 旧 AI 的日志——它的感受和想记住的事 |
| `用户.md` | 旧 AI 对你的了解——称呼、性格、偏好、禁忌 |
| `people.md` | 你身边的人——关系、印象、重要性 |
| `memories.md` | 你们一起经历过的事，按时间顺序 |

文件名不必严格一致，`.md` 或 `.txt` 都行；HCEM 会读取这个目录下的文本文件并逐条融合。

## 放好之后

重启 DSH 即可，融合过程不需要你操作。

## 注意

这个目录里只保留本说明文件。**你放进去的记忆属于私人内容**，`.gitignore` 已经把它排除在外——除了本文件，目录里的其他内容不会被提交，也不会被推到 GitHub。

如果你确实想连记忆一起备份到仓库（不建议，公开仓库等于公开你的私人对话），需要先自己删除 `.gitignore` 里的相关规则。
