# HCEM 安装必看

> 适用版本：**HCEM v0.0.3.2**
> 这份文档只讲一件事：**GitHub 包里没有、但运行 HCEM 必须自己准备的东西。**
>
> GitHub 仓库只包含代码和文档，不包含模型权重、Python 环境、桌面可执行文件、ffmpeg 二进制和运行数据。

---

## 一、先确认你拿到了什么

仓库里会有：

```
plugin/          DSH 插件源码
ui/              桌面中控源码（Tauri + Electron）
docs/            设计/验证/训练文档
models/models.md 模型清单（只有说明）
HCEM.exe         预构建桌面中控（Windows x64）
start-services.mjs
tools/           辅助脚本（不含 ffmpeg）
```

仓库里**没有**：

| 缺失项 | 为什么不在仓库 | 去哪里准备 |
|---|---|---|
| GGUF / ONNX / TFLite 模型权重 | 体积约 13 GB | 见 `models/models.md`，按目录放 |
| `python-venv/` | 约 3 GB，含平台相关二进制 | 本文第五节 |
| ffmpeg / ffprobe / ffplay | 二进制较大、许可证独立 | 本文第六节 |
| CrispASR 运行时 | 约 1 GB | 见 `models/models.md` |
| `fpcalc.exe` | Chromaprint 指纹工具 | 见 `models/models.md` |
| `data/` | 用户私有数据（情绪/记忆/人物网） | 首次运行自动生成 |
| `logs/` | 运行日志 | 首次运行自动生成 |
| 云端 API Key | 本版本不需要 | 不填也能全本地运行 |

## 二、系统要求

### 最低

- Windows 10/11 x64
- 16 GB 内存
- 8 GB 显存的 NVIDIA 显卡（Qwen2.5-VL / OmniDimen 错峰使用）
- 约 20 GB 可用磁盘（模型 13 GB + Python 3 GB + 数据/日志）
- 能运行 DSH 的桌面环境

### 没有 8 GB 显卡时

- 仍可只用 Qwen3-1.7B（CPU）和 Embedding（CPU）做文字陪伴
- 视觉（8091）和 Omni（8098）可能启动失败；插件会在日志里说明，不会静默假装成功

### 必须的软件

| 软件 | 用途 | 说明 |
|---|---|---|
| DSH | 插件宿主 | 需要支持 bundle/plugin 的当前版本 |
| Node.js | 运行插件和启动脚本 | DSH 自带 Node 时可用它；否则装 Node 20+ |
| PowerShell 5+ | 窗口枚举、进程回环录音、OCR 辅助 | Windows 自带 |
| Rust 1.90+ + MSVC Build Tools | 只有自己构建 `HCEM.exe` 时需要 | Tauri 2.12 要求 |
| WebView2 Runtime | Tauri 窗口 | Windows 10/11 通常已有 |

> `ui/package.json` 里还有一套 Electron 入口；用 Tauri 构建时不需要 Electron。

## 三、安装 DSH 插件

1. 把 `plugin/` 整个目录放到 DSH 的插件/包目录（或用 DSH 插件管理器从本地路径安装）。
2. 确认 `plugin/package.json`、`plugin/cordis.patch.yml`、`plugin/index.mjs` 在同一个目录。
3. 重启 DSH。
4. 在 DSH 中启用 **HCEM**，并确认插件没有因为“安全阀自检失败”拒绝加载。
5. 如果使用桌面中控，再启动 `HCEM.exe`（见第四节）。

插件依赖的 peer：

```json
"@deepseek-ai/dsh-llm": "*",
"@deepseek-ai/dsh-tools": "*"
```

DSH 版本过旧时，插件 API 可能不匹配；以你安装的 DSH 的插件文档为准。

## 四、桌面中控 `HCEM.exe`

**本包根目录已附带预构建的 `HCEM.exe`（Windows x64，2026-11-24 构建）。**

### A. 直接使用

确认 `HCEM.exe` 和 `plugin/`、`models/` 在同一层，双击启动即可；插件通过管道与它通信。

校验值：

```
大小：10,231,296 字节
SHA256：502123EE19A04330C79E96055A09DE1D267F1244CDF5352E42DC1DF8FEFB82B8
```

如果 Windows 提示来源未知，这是本地构建的未签名 exe；可以自己从 `ui/src-tauri` 重新构建。

### B. 自己构建（Tauri）

前置：

- Rust 1.90+
- Visual Studio Build Tools（MSVC + Windows SDK）
- WebView2 Runtime

```powershell
cd ui/src-tauri
cargo build --release
# 产物：ui/src-tauri/target/release/app.exe
# 改名为 HCEM.exe，放到安装根目录
```

构建时如果 Cargo 缓存/临时目录在系统盘，建议设置：

```powershell
$env:CARGO_HOME="E:\HCEM\.cargo"
$env:RUSTUP_HOME="E:\HCEM\.rustup"
$env:CARGO_TARGET_DIR="E:\HCEM\.rust-target"
$env:TMP="E:\HCEM\.tmp"
$env:TEMP="E:\HCEM\.tmp"
```

## 五、模型：按目录放，一个都不能改名

完整清单、大小、端口、下载提示见 [`models/models.md`](models/models.md)。这里只列**运行必需**和**容易漏**的：

### 5.1 文字 / 向量 / 视觉（必需）

| 目录 | 关键文件 | 端口 | 作用 |
|---|---|---|---|
| `Qwen3-1.7B-Q4_K_M/` | `Qwen3-1.7B-Q4_K_M.gguf` | 8093（CPU） | 分流、抽卡、摘要第一步 |
| `Qwen3-Embedding-0.6B-Q8_0/` | `Qwen3-Embedding-0.6B-Q8_0.gguf` | 8094（CPU） | 向量检索，常驻 |
| `OmniDimen-4B-Emotion-GGUF-q4_K_M/` | `OmniDimen-v1.0-4b-Emotion_q4_K_M.gguf` | 8098（GPU） | 对话/情绪/摘要第二步 |
| `Qwen2.5-VL-3B-Instruct-GGUF/` | `Qwen_Qwen2.5-VL-3B-Instruct-Q4_K_M.gguf` + `mmproj-Qwen2.5-VL-3B-Instruct-Q8_0.gguf` | 8091（GPU） | 看屏幕/视频/OCR |
| `llama.cpp-cuda/` | `llama-server.exe` | — | 所有 GGUF 的 GPU 运行时 |

> Qwen2.5-VL 必须 **model + mmproj 两个文件**都在；缺 mmproj 时视觉会失败。
> `llama.cpp-cpu/` 可选，用于 Qwen3-1.7B 的 CPU 推理。

### 5.2 听觉（想要“听见”就必需）

| 目录 | 关键文件 | 作用 |
|---|---|---|
| `CrispASR-v0.8.53-win-x64-cuda/` | `crispasr.exe` | ASR 运行时 |
| `qwen3-asr-crisp/` | `qwen3-asr-0.6b-q8_0.gguf`（融合版） | 台词/歌词转写 |
| `emotion2vec+base/` | `model.pt`、`e2v_test.py` | 语音情感 |
| `panns/` | PANNs CNN14 | 声源分类 |
| `chromaprint/` | `fpcalc.exe` | 音乐指纹 |
| `3d-speaker/` | ECAPA-TDNN | 声纹（可选） |

> Qwen3-ASR 必须用 **融合版 GGUF**（mel 滤波器烤在主模型里）；主模型 + mmproj 分离版 CrispASR 读不了。

### 5.3 音乐情感 / 人脸 / 语音输出（可选但推荐）

| 目录 | 关键文件 | 作用 |
|---|---|---|
| `vibenet-main/` | VibeNet（EfficientNet ONNX） | 音乐情感 valence/energy |
| `hsemotion/` | HSEmotion B0（TFLite） | 人脸 8 类情绪 |
| `Fun-CosyVoice3-0.5B-2512/` | CosyVoice3 GGUF | 语音输出 |

HSEmotion B0 文件大小应为 **8,291,808 字节**，SHA256：

```
8A59E85CD96AEFA39752A75C9CBA7F1B3DD38AE3BF98D8EA2835E12B0DBF3735
```

不一致就重新下载，别用别的 B0 版本硬替换。

### 5.4 模型许可证

模型权重不随本项目分发；每个模型的许可证以原始发布页为准。商用/再分发前请自己确认。

## 六、Python 运行时（`python-venv/`）

### 6.1 需要哪个 Python

- Windows x64
- Python **3.12**（本项目实测 3.12.14）
- 虚拟环境放在安装根目录，路径必须是：

```
python-venv\Scripts\python.exe
```

插件会优先用这个路径；也可用环境变量 `HCEM_PYTHON` 覆盖。

### 6.2 必装包

```powershell
# 1) CPU 版 torch（不要装 CUDA 版，emotion2vec 只用 CPU）
python -m pip install torch torchaudio --index-url https://download.pytorch.org/whl/cpu

# 2) emotion2vec / VibeNet / 人脸情绪
python -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple `
  funasr onnxruntime librosa audioread pydub soundfile scipy numpy `
  opencv-python-headless ai-edge-litert
```

实测版本：

| 包 | 版本 |
|---|---|
| torch | 2.15.0+cpu |
| torchaudio | 2.11.1+cpu |
| funasr | 1.4.29 |
| onnxruntime | 1.32.0 |
| librosa | 1.0.1 |

### 6.3 funasr 安装卡住怎么办

`funasr` 会依赖 `editdistance==0.5.2`，这个版本在 Windows 上可能触发源码构建并卡住。

先装预编译版：

```powershell
python -m pip install --only-binary=:all: -i https://pypi.tuna.tsinghua.edu.cn/simple editdistance
```

再装 funasr；如果依赖仍报缺失，按报错逐个补：

```
omegaconf torch_complex kaldiio kaldi-native-fbank safetensors sentencepiece
tensorboardX tiktoken transformers umap_learn websockets hydra-core
jaconv jamo jieba modelscope oss2 rapidfuzz
```

`pip install funasr` 可能提示依赖冲突，但只要下面这条能跑通就可以用：

```powershell
python -c "import funasr; print(funasr.__version__)"
```

### 6.4 验证

```powershell
python -c "import torch, funasr, onnxruntime, librosa; print('ok')"
python models\emotion2vec+base\e2v_test.py <任意wav>
```

`e2v_test.py` 用脚本所在目录定位模型，不再写死安装路径。

## 七、ffmpeg / 声卡 / 系统工具

### 7.1 ffmpeg

仓库不带 ffmpeg 二进制。放到：

```
tools\ffmpeg-9.0.2-essentials_build\bin\ffmpeg.exe
tools\ffmpeg-9.0.2-essentials_build\bin\ffprobe.exe
tools\ffmpeg-9.0.2-essentials_build\bin\ffplay.exe
```

用于：故事板拼图、音频解码、视频抽帧、TTS 播放。

版本不必严格 9.0.2，但需要 `ffmpeg`、`ffprobe`、`ffplay` 三个都在。

### 7.2 系统音频

- 使用 Windows WASAPI **系统回环** 或 **按进程回环**
- 不需要安装虚拟声卡
- 需要有输出设备；没有音频播放时录音会返回“数据太少”，这是正常空采

### 7.3 屏幕捕获

- 多屏通过 Windows 图形接口枚举
- 不需要管理员权限
- 空桌面（只有壁纸/任务栏）会被跳过
- OCR 依赖 Qwen2.5-VL，不另装 OCR 引擎

## 八、启动顺序

推荐：

```
1. 启动 DSH
2. DSH 加载 HCEM 插件
3. 启动 HCEM.exe（桌面中控，可选）
4. 插件按开关拉起模型：
     - embedding 常驻
     - 视觉开关 → qwen25vl :8091
     - 听觉/本地分流 → omni :8098 / qwen3 :8093
```

`start-services.mjs` 只是**最小启动器**（qwen3 + embedding），模型生命周期实际由插件 `plugin/lib/services.mjs` 管理；不要用它替代 HCEM.exe 的开关同步。

### 端口检查

```powershell
Test-NetConnection 127.0.0.1 -Port 8091
Test-NetConnection 127.0.0.1 -Port 8093
Test-NetConnection 127.0.0.1 -Port 8094
Test-NetConnection 127.0.0.1 -Port 8098
```

| 端口 | 服务 |
|---|---|
| 8091 | Qwen2.5-VL |
| 8093 | Qwen3-1.7B |
| 8094 | Embedding |
| 8097 | 插件语音/事件通道（不是模型） |
| 8098 | OmniDimen |
| 8099 | TTS（语音输出时） |

## 九、安装后怎么验证

### 9.1 插件

- DSH 里能启用 HCEM，且没有“安全阀拒绝加载”
- `hcem_status` 返回 ready
- `hcem_vision(kind="status")` 能看到采集状态

### 9.2 视觉

- 打开视觉开关，看屏幕一次
- 应产生 `data/captures/shot-*`，并在 `video_context`/视觉记忆里出现描述
- 桌面上有字时，描述里应能抄出字

### 9.3 听觉

- 播放一段有台词/歌词的音频
- 调 `hcem_listen(mode="voice", seconds=5)`
- 结果应同时有：`text`（台词/歌词）、`emotion`、`music`（如适用）、`fp`

### 9.4 笔记

- 看一段视频后停下
- 约 10 分钟无新视频记忆后，`video_context` 出现 `modality=note`
- `hcem_vision(kind="notes")` 能查到
- 笔记里同时有画面段和 `【台词/歌词】`

## 十、常见故障对照

| 现象 | 先查 |
|---|---|
| 8091 起不来 | Qwen2.5-VL 的 `model` 和 `mmproj` 是否都在 |
| 8098 起不来 | 显存是否够；是否有 TTS/视觉占着 |
| 视觉全失败 | 是否被旧 SmolVLM 8092 配置误导；当前只用 8091 |
| 有音乐没词 | `audioTick` 是否跑了 ASR；PANNs 判成 music 也会跑转写 |
| 语音情感为空 | `funasr`/`torch` 是否装好；`e2v_test.py` 能否单独跑 |
| 音乐情感为空 | `onnxruntime`/`librosa` 是否装好；`vibenet-main` 是否在 |
| 声音条/故事板不生成 | ffmpeg 是否在 `tools/.../bin`；图片是否 ≥4 帧 |
| TTS 不出声 | CosyVoice 模型、8099、ffplay 是否就绪 |
| 插件加载失败 | 安全阀自检；不要改 `safety.mjs` 的指纹 |
| 没有截图 | 桌面默认不自动截；需要搭话/明确看屏/鼠标巡逻 |

## 十一、隐私与数据

- 画面、声音只在本机处理；代码不含云端密钥。
- `data/` 是私有数据：记忆、情绪、角色卡、人物网、日志都可能在里面。
- 分享安装目录前，至少删除：`data/`、`logs/`、`python-venv/`、`models/`、`HCEM.exe`。
- 本项目是情绪陪伴系统，不是医疗设备；不能替代心理治疗或危机干预。
