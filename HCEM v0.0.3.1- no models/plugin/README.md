## 这是什么

HCEM 是 DeepSeek Harness（DSH）的插件。三个核心：

**① 情绪不是标签，是连续变化的颜色**

```
H 色相（0~360）  六色环：快乐0° 惊讶60° 恐惧120° 悲伤180° 厌恶240° 愤怒300°
S 饱和度（0~100）情绪强度 / 语气
L 明度（0~100）  自信 / 话量
```

三对对立色互相牵制（快乐↔悲伤、惊讶↔厌恶、恐惧↔愤怒），
每种情绪强度 = `max(0, 1−距离/180)`，所以对立两极强度和恒为 1。

情绪会自己回落：距离基线越远回落越快，接近基线变慢（弹簧式消振）。

**② 记忆不是数据库，是会淡忘的东西**

三个平行大区，每个分区一个独立库文件：

| 大区 | 分区 | 存什么 |
|---|---|---|
| **语义**（8 区） | 上下文 2h → 快池 2h → 观察池 24h → 保留池 72h → 生活/知识 → 冷存 | 对话、知识、日记、人物 |
| **视觉**（7 区） | 视觉上下文 2h → 快池 → 观察池 → 保留池 72h → Ⅰ区 → Ⅱ区 | 画面描述 + 关键帧 |
| **听觉**（4 区） | 听觉上下文 2h → 缓冲池 72h → Ⅰ区 → Ⅱ区 | 转写 + 指纹/声纹 |

四枚情绪戳：

- **α** 编码时 AI 的情绪
- **β** 内容本身的情绪
- **γ** 清醒度（0~1，由 α/β 重合度 + δ 决定）
- **δ** 价值戳（δ₁ 缓冲池每 3h×0.95 / δ₂ 生活知识区每 30 天×0.7）

**③ 感知是自己的眼睛耳朵**

| 能力 | 怎么做 |
|---|---|
| 看屏幕 | 截屏 → 帧级漏斗 → SmolVLM（日常）/ Qwen2.5-VL（看视频）|
| 看视频文件 | ffmpeg 镜头切分 → 抽帧 → 九宫格拼图 → 视觉模型概括 |
| 听声音 | 系统回环 / **按进程回环**（只看视频时只抓浏览器）→ PANNs 分 11 类 → 人声转写+情绪 / 音乐情感+指纹 |
| 快速划鼠标 | 在一块区域快速移动 3 秒 → 看一眼那块区域（带 3~5 分钟动态冷却）|
| 主动搭话 | 搭话度档位（话痨/好奇/安静）+ L 修正 + 变化率 |

**画面和声音永不上传**。只有「描述文字」进对话模型；云端兜底只在本地连续失败 2 次时考虑，
且只发 ≤1024px 的合成故事板（日 5 次 / 时 1 次）。

## 情绪如何影响记忆

这是 HCEM 和普通记忆插件最大的区别：

```
γᵥ = clamp(0.6 × (S_α/100 + 视觉模型评分), 0, 1)     ← S_α 是 AI 看到画面那一刻的饱和度
γ₀ = 0.5γᵥ + 0.3γₐ + 0.2γₘ
δ₀ = 0.5×(0.6δᵥ + 0.4δₐ) + γ₀
p₀ = pᵥ + pₐ                                         ← 喜好度
V_Ⅱ = 2.5γ₀ + 3.5p₀ + 4δ₀                            ← Ⅱ区压缩用
```

**AI 在什么情绪下看到的东西，决定那段记忆有多重要。**

喜好度 p₀ 的三条来源：

- AI 看视频时逐帧打分
- AI 在记忆到期前抢救（+0.4，每块只能救一次）
- 用户开口评价（AI 替用户判：喜欢 +0.4 / 一般 +0.1 / 没评价算弃权）

## 痛苦安全阀

不是「一个条件不满足就报警」，而是两层：

**五条件打分**（连续值）→ **概率乘积组合**（不是加法）→ **极化检测**（突发才收紧，稳定高压压平）

然后进 **Aqua 水槽**：

```
每分钟漏 0.8 点水
加水权重：重复/辱骂 5 > L 极端 4 > S 过高 3 > 色相波动 2 > 资源占用 1
≥95 出手 / ≥60 提示 / ≥30 记录
```

**为什么要水槽**：一有信号就出手，AI 会变成一点风吹草动就停摆的废人。
有了水槽，短暂波动会自己漏掉，只有持续累积的压力才让系统真正出手。

危机信号（自伤/告别式表述）不走水槽，直接出手，转向人物关系网求助。

## 会话隔离

只在 `agentPreset === 'hcem'` 的会话生效：

| 环节 | 隔离方式 |
|---|---|
| 18 个 `hcem_*` 工具 | 全部有会话门禁，非 HCEM 会话调用直接抛错 |
| 情绪结算 / 记忆写入 / 记忆注入 | `if (!isHcemSession(...)) return` |
| TTS 语音输出 | 同上 |
| 提示词注入 | 8 个段落全部带门禁 |
| 感知上报 | 6 处，全部带门禁 |

判定逻辑（严格）：读会话投影 → 投影缺失回落 `header.agentPreset` → **都读不到就按「非 HCEM」处理**（宁可 HCEM 自己失效，也不泄漏进标准会话）。

HCEM 的工具全部带 `hcem_` 前缀，不与 DSH 原生工具撞名。

## 数据位置

```
<安装目录>\
├── HCEM.exe              启动悬浮球
├── data\                 你的数据（记忆分区 / 日记 / 角色卡 / 声纹）
├── models\               模型
├── plugin\               插件本体（这个目录）
├── docs\                 文档（工作日志 / 算法 / 交接）
└── ui\                   桌面中控源码
```

记忆分区在 `data\zones\`，每个分区一个 `.sqlite` 文件。
