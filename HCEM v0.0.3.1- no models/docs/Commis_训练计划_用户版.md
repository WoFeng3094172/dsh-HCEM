# 热菜助理 Commis · 训练计划（用户版）

> **Commis** 是厨房里给主厨打下手、备料摆盘的那位「热菜助理」。
> 它不管做菜（回答），只负责把工具按顺序摆到主厨手边——所以Commis叫这个名字。

> 面向：决定"要不要开 Commis、要不要自己训"的用户。
> 一句话：**它是可选增强，默认关闭；不开完全不影响现有行为。**

---

## 1. 它到底是什么

现在 HCEM 找工具的方式是"向量检索"：把你的需求变成向量，和 15 个工具的说明比相似度，取前 3 个交给模型。

Commis 是**在检索结果上再学一层排序**：

```
最终分 = 0.7 × 向量相似度 + 0.3 × Commis打分
```

它不新增工具、不改候选集合，只决定"这 3 个里谁排前面"。模型输出的是"在当前情绪/资源状态下，我更可能选哪个工具"。

## 2. 开了有什么好处，有多大

| 指标 | 现状（不开） | 训练良好后 |
|---|---|---|
| top-1 命中 | 约 67%（6/9） | 约 80~90% |
| top-3 召回 | 100% | 100%（不变） |

**结论：收益是"少一次选错再补救"**，日常体感差别不大。如果你的工具使用很集中（基本只用 read/edit/grep），开了也几乎没有变化。

## 3. 什么时候值得开

✅ 值得：你经常让 HCEM 跑命令、看屏幕、建日程，工具选择经常差一点；你愿意按第 5 节收集几百条记录。
❌ 不值得：只是日常聊天；不愿收集数据；不能容忍任何"行为变化"。

## 4. 风险（先读）

| 风险 | 说明 | 缓解 |
|---|---|---|
| 自标注闭环 | 拿 AI 自己的选择当标签，会越训越偏 | 只收录**你纠正过的**和**你明确点名的** |
| 数据太少 | 几十条训出来的东西等于背答案 | 硬门槛 40 条，建议 2000+ |
| 行为不可解释 | 出现"心情好就选 read"这类怪现象 | 开关随时可关；删模型即恢复原状 |
| 情绪当标签 | 情绪是**上下文**，不是"正确答案" | 只用它做特征，不用它定标签 |
| 覆盖检索 | 头权重过大导致排序被它主导 | 混合权重上限 0.6，默认 0.3 |

## 5. 训练步骤（你来做）

### 第一步：收集（1~2 周）

HCEM **不能自动观察自己最后调了哪个工具**（DSH 没暴露调用事件），所以标签只能靠你：

- 它用对了、你想记下来 → 说「记一下：刚才那句该用 read」
- 它用错了、你纠正完 → 说「记一下：该用 pwsh」

它会调用 `hcem_commis(action=log, query=…, tool=…)` 写进 `data/classifier/labels.jsonl`。
**不要**让它事后凭记忆批量补标签（会掺假），也不要让它拿自己的选择当标签。

建议目标：

| 项 | 目标 |
|---|---|
| 总条数 | ≥ 2000 |
| 每个常用工具 | ≥ 50 |
| 用户纠正条数 | ≥ 200 |
| 时间跨度 | ≥ 1 周（覆盖不同状态） |

### 第二步：训练

菜单 → 设置 → 热菜助理 Commis → 打开（此时只是开开关，没模型时行为不变）。

然后让 HCEM 训练：

> 「用现有的选择日志训练一下Commis」

它会调 `hcem_commis(action=train)`，返回训练集/留出集准确率。

或者自己跑：

```bash
node "HCEM v0.0.3.1/plugin/tools/train-classifier.mjs"
```

### 第三步：验收

| 检查 | 通过标准 |
|---|---|
| 留出集准确率 | ≥ 80% |
| 训练集与留出集差距 | ≤ 10%（差距大 = 过拟合，别用） |
| 每类样本数 | 最小类 ≥ 30 |

不达标就**不要开**，继续收集数据。

### 第四步：观察 3 天

开了之后看三件事：

1. 工具选错是否变少
2. 有没有出现"总是选某个工具"的偏执
3. 情绪低落/资源紧张时行为是否变得奇怪

任何一条不对 → 菜单关掉开关（立即恢复）。

## 6. 回滚

| 操作 | 效果 |
|---|---|
| 菜单关掉「热菜助理 Commis」 | 立即回到纯检索 |
| 删除 `data/classifier/head.json` | 同上，但开关可以留着 |
| 删除 `data/classifier/labels.jsonl` | 清空训练数据（不可恢复） |

## 7. 一句话总结

**不开 = 现状；开 = 让"选工具"更准一点，风险可控、随时可退。**
数据不够就别开，别把「AI 自己的选择」当真理去训练它。
