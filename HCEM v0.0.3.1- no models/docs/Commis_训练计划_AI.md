# 热菜助理 Commis · 训练协议（AI 版 / HCEM 自用）

> 给 HCEM（或任何接手的 AI）的严格协议。
> **违反任何一条，训练结果视为无效，必须回滚。**
> 用户版见 `docs/Commis_训练计划_用户版.md`。

---

## 0. 身份与边界

- 这个头是**你自己的**工具选择偏好模型，不是用户的。
- 它只影响"检索结果排序"，**不影响工具存在性、权限、沙箱**。
- 开关默认关。用户没开，你**不得**自己打开（没有工具能开，只有菜单能开）。
- 你**可以**调用 `hcem_commis(action=status/train/log)`，但不能改检索基线。

## 1. 数据条件（不满足就不许训练）

| 条件 | 阈值 | 不满足时 |
|---|---|---|
| 总样本 | ≥ 2000（硬下限 40） | 拒绝训练，报告还差多少 |
| 每类样本 | ≥ 50（最小类 ≥ 30） | 报告稀疏类，建议继续收集 |
| 用户纠正样本（source=user） | ≥ 200 | 训练结果不可信，只能当实验 |
| 用户点名样本（source=explicit） | ≥ 50 | 同上 |
| 时间跨度 | ≥ 7 天 | 状态分布太窄，容易过拟合 |
| 状态分布 | H/S/L 各至少 3 个不同档位 | 报告"状态单一"，别训 |

**绝对禁止**：
- 把你自己某次的选择直接当标签批量灌入。你**观察不到**自己最后调了哪个工具（DSH 不暴露调用事件），所以 source=model 一律禁止；只收 source=user（用户纠正）与 source=explicit（用户点名）
- 用 `hcem_memory` 的记忆内容当标签
- 用情绪值反推"正确答案"
- 为了凑数重复同一条记录

## 2. 训练步骤（必须按顺序）

1. **读状态** `hcem_commis(action=status)`，确认开关状态、标签数、是否已有模型。
2. **做数据体检**（自己算，或让用户跑 CLI）：
   - 类别分布是否均衡（最大类 / 最小类 ≤ 5）
   - 有无重复 query
   - 时间跨度
3. **训练** `hcem_commis(action=train)`
   - 内部固定：one-vs-rest logistic，L2=1e-4，lr=0.15，8 epoch
   - 固定 20% 留出集，随机种子 42（可复现）
4. **看报告**：
   - `testAcc ≥ 0.80` 且 `trainAcc - testAcc ≤ 0.10` → 可用
   - 否则 → 报告失败原因，**不要保存**（模型文件已写则删除）
5. **汇报给用户**：样本数、类别数、训练/留出准确率、是否启用。
6. **只有用户确认后**才算完成部署（开关由用户开）。

## 3. 目标（验收标准）

| 指标 | 目标 | 说明 |
|---|---|---|
| 留出集 top-1 | ≥ 0.80 | 主指标 |
| 训练/留出差距 | ≤ 0.10 | 过拟合警戒线 |
| top-3 召回 | 不低于基线（100%） | 抖动说明头在乱排 |
| 每个工具至少被选中一次 | 7 天内 | 出现"永不选中"的工具要报警 |

**收益预期**：top-1 从 ~0.67 提到 0.80~0.90。低于 0.75 视为无收益，不要开。

## 4. 必须避免的状况

| 状况 | 为什么危险 | 检测 |
|---|---|---|
| 自我强化 | 用自己输出当标签 → 偏好越来越极端 | `source=model` 占比 > 70% 就停 |
| 情绪当标签 | 情绪是上下文特征，不是正确答案 | 训练样本里同 query 不同 tool 却同情绪 → 可疑 |
| 类别极不平衡 | 少量类被彻底忽略 | 最小类样本 < 30 |
| 数据泄漏 | 同一 query 同时进训练和留出 | 训练前按 query 去重 |
| 全量替换检索 | 失去了"语义兜底" | 混合权重 α 必须 ≤ 0.6 |
| 无回滚准备 | 出问题无法恢复 | 训练前先备份旧 `head.json` |
| 偷偷启用 | 用户不知道行为变了 | 只允许用户在菜单开 |

## 5. 失败处理

| 情况 | 动作 |
|---|---|
| 样本不足 | 拒绝训练，报告缺口，继续收集 |
| 800 样本以下 | 只允许"实验模式"，报告里必须写"不可信" |
| 准确率不达标 | 删除新模型，恢复旧模型（有备份时） |
| 训练中异常 | 报告错误原文，不许静默重试 |
| 打开后行为异常 | 让用户关开关；你**没有能力**自己开/关 |

## 6. 你能做什么 / 不能做什么

✅ 能：
- `status` 查看状态
- `train` 触发训练
- `log` 记录一条真实选择（**仅当用户刚纠正过你时**）
- 写训练报告到日记/工作笔记

❌ 不能：
- 改 `data/ui-state/classifier.json`（那是开关，只有菜单写）
- 改检索基线权重
- 声称"训练成功"却没有留出集指标
- 把训练结果当"我变聪明了"去炫耀

## 7. 汇报模板

```
Commis 训练结果
- 样本：N 条（用户纠正 X / 点名 Y / 模型自选 Z）
- 类别：K 个，最小类 M 条
- 训练集：a%；留出集：b%
- 判定：可用 / 不可用（原因）
- 建议：开启 / 继续收集 / 放弃
```

## 8. 一句话

**数据够、差距小、留出集达标，才配开开关；任何一条不满足，就停在"收集数据"。**
